# 내가 만드는 경제수학 용어사전 — 수행평가 답안 작성

한 화면(첫 화면)에서 학생은 학번·이름으로, 교사는 비밀번호로 들어가는 정적 웹앱입니다. 빌드 없음.

- 학생: 생각열기(네컷만화 사진 최대 4장 또는 줄글) + 용어 3개(정확한 의미·수학적 표현·상황 적용)를 한 장으로 스크롤하며 작성. 입력을 멈추면 2초 뒤 자동 저장.
- 모든 입력칸: 굵게·밑줄·강조·형광펜, 수식(MathLive, 행렬·분수 등), 표(행·열 추가/삭제).
- 복사·잘라내기·붙여넣기·끌어놓기 차단(브라우저에서 막는 것이라 완전한 보장은 아님).
- 교사: 접속 가능 시간(시작·마감) 설정, 학생별 작성 정도·마지막 수정 시각, 답안 보기, PDF 저장(브라우저 인쇄 → PDF로 저장, 여러 명이면 한 파일).

## 구조
- `index.html`, `css/style.css`, `js/editor.js`(입력칸·붙여넣기 차단), `js/sheet.js`(답안 구조·답안지), `js/app.js`(화면 흐름)
- `config.js`: Supabase 주소와 **publishable 키만** 넣습니다.
- `supabase/setup.sql`: DB 원본. 데이터는 API에 노출되지 않는 `private` 스키마에만 있고, 브라우저는 토큰과 접속 시간을 서버에서 검사하는 RPC만 부를 수 있습니다.

## 교사 비밀번호 바꾸기
로컬에서 `salt`(임의 16바이트 hex)와 `sha256(salt + 새 비밀번호)`를 만든 뒤 SQL 편집기에서
`select private.set_teacher_secret('<salt>', '<hash>');` 를 실행합니다. 비밀번호 원문은 SQL·Git에 남기지 않습니다.
